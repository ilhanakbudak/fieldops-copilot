# Bundled fonts

Self-hosted rather than loaded from a CDN. A technician opening this on a phone
in a customer's basement has poor signal and no patience for a render-blocking
request to somebody else's server — and a font that arrives late is a page that
reflows under the reader. The latin subsets together are ~78 KB.

| Font | Version | License |
|---|---|---|
| Inter (variable, latin subset) | v20 | SIL Open Font License 1.1 |
| JetBrains Mono (variable, latin subset) | latest | SIL Open Font License 1.1 |

The SIL OFL permits bundling and redistribution with software. Full text:
